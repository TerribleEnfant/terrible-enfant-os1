# Terrible Enfant — Workflows & Cadencias

## Ritmo operativo semanal

```
Lunes        → Status drops por área (cada responsable)
Martes       → Weekly sync (Hache + leads) · 45 min
Martes PM    → Decisiones publicadas por Fanny
Miércoles–Viernes → Ejecución
```

## Weekly sync — estructura

- **Participantes:** Hache, Comando, Fanny + leads relevantes
- **Duración:** 45 minutos
- **Input:** Status drops del lunes (llega preparado, no se lee en la reunión)
- **Output:** Decisiones con owner y deadline — publicadas el mismo día por Fanny

## Weekly Report — template por área

Cada responsable de área completa este template antes del lunes 18hs.
Nombre del documento: `[Área] · [Mercado] · Semana [fecha lunes]`

**Secciones:**
1. Estado general del área (un párrafo)
2. Actividades de la semana (tabla: actividad / status 🟢🟡🔴 / notas)
3. Bloqueos y dependencias (tabla: bloqueo / depende de / urgencia / acción requerida)
4. Próximos pasos (tabla: acción / responsable / deadline / prioridad)
5. Señales tempranas (opcional — algo que podría convertirse en problema)
6. Necesito del sync (máximo 3 ítems — qué necesita resolverse el martes)

## Cadencias adicionales

**Bi-semanal — Comando + Freequency (30 min)**
Alineación creativa ARG↔BRA. Sin Hache. Campañas, collabs, contenido. Donde se coordina la GIGA-Campaña en la práctica.

**Mensual — Update a Jorge (inversor)**
No es reunión. Es un documento que Mariano escribe y envía. Formato: titular bullish → hechos concretos → nota de cautela al final si corresponde.

**Fase de lanzamiento BRA — thread diario WhatsApp**
Solo durante las primeras 4–6 semanas de operación BRA. Para bloqueos que no pueden esperar al martes. Se cierra cuando la operación se estabiliza.

## Task Board — propiedades clave

Cuando se crea en Notion como database:

| Propiedad | Tipo |
|---|---|
| Tarea | Título |
| Área | Select (6 áreas) |
| Mercado | Select (ARG / BRA / Ambos) |
| Responsable | Person |
| Status | Select (Por hacer / En curso / Bloqueada / Completada / Cancelada) |
| Prioridad | Select (Alta / Media / Baja) |
| Deadline | Date |
| Origen | Select (Weekly Report / Sync / Decisión directa) |

**Regla:** Solo Fanny crea y actualiza tareas en el Task Board. Los responsables de área reportan en sus Weekly Reports — no administran la database directamente.
