# Skills Registry

> Las skills/comandos son una Capability pero viven físicamente en `.claude/` (el Charter — el
> runtime de Claude Code los descubre ahí). Este registry los vincula al modelo 4C por referencia.

| Skill / Comando | Sirve (4C) | Toca (WAT / artefacto) | Propósito |
|---|---|---|---|
| `upc` (`.claude/commands/upc.md`) | Cadence | git / `TL_CORE_GITHUB` | Cerrar la sesión con un commit limpio y push a GitHub. |

> Nuevas skills: agregar el archivo en `.claude/` y una fila acá. No mover el archivo fuera del
> Charter.
